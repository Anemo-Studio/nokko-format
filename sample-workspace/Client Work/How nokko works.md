# How nokko works

Everything here is a plain Markdown file in the folder you picked. Delete a
file and the thing disappears; edit it in Obsidian and nokko follows.

## The shape

A **space** is a top-level folder — this one is Client Work. A **board** is one
file inside it, and every board in the space inherits the space's statuses
unless it declares its own.

## Tracking time

Start a timer on any task. Stopping writes one line under the task:

`⏱ 2026-11-06 09:15-12:30 (3h15m) — first pass at the hero`

Reports add those up, per client or per tag.

## Estimating

`[est:: 6h]` on a task feeds the group totals, the board cards and the
workload forecast. Nothing is ever written that you did not type.
